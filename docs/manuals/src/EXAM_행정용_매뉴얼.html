1. 시작하기

접속 주소

지점주소

두 지점은 데이터가 완전히 분리되어 있습니다. 내가 근무하는 지점 주소로 접속해야 해당 지점 학생·일정이 보입니다. 휴대폰에서는 브라우저에서 접속한 뒤 '홈 화면에 추가'를 해 두면 앱처럼 쓸 수 있습니다.

로그인

  1. 이름과 PIN(4~6자리 숫자)을 입력합니다. PIN은 원장님이 계정을 만들 때 알려드립니다.
  2. 처음 로그인한 뒤에는 오른쪽 위 계정 메뉴에서 PIN 변경을 눌러 본인만 아는 번호로 바꿔 주세요.
  3. PIN을 잊었으면 원장님께 비밀번호 재설정을 요청합니다. 재설정되면 기존에 로그인된 기기는 자동으로 로그아웃됩니다.

화면 구성

  • 왼쪽 사이드바 — 역할(행정)에 맞는 메뉴만 보입니다. 메뉴를 눌러도 본문만 바뀌므로 화면 전체가 새로고침되지 않습니다.
  • 현재 위치 — 본문 위에 '그룹 › 메뉴' 형태로 지금 위치가 표시됩니다.
  • 전체 보기 — 사이드바 아래 '전체 보기'를 누르면 내가 쓸 수 있는 모든 화면과 설명이 한 페이지에 나옵니다.
  • 휴대폰 — 왼쪽 위 ☰ 버튼으로 메뉴 서랍을 열고, 자주 쓰는 메뉴는 하단 메뉴바에서 바로 이동합니다.

2. 하루 업무 흐름 (행정 핵심 업무)

출근 직후 — 오늘 현황 확인

  1. 홈 화면 '오늘 할 일'과 '지금 할 일'에서 처리할 업무를 확인합니다. 업무를 누르면 그 자리에서 결과 선택·메모·완료가 됩니다.
  2. 오늘 현황 › 오늘 대시보드에서 오늘 일정, 보강·재시 확정 현황, 출석률, 오늘 클리닉을 봅니다.
  3. 입력창에 오늘 일정 보여줘 라고 쓰면 오늘 일정·할 일을 바로 볼 수 있습니다.

TIP · 결석·행정실 기록 고치기

보강·재시 관리

  • 보강·일정 › 보강·재시에서 예정·오늘·지난 미완료·완료를 확인합니다. Slack과 입력창으로 등록된 일정도 모두 여기 모입니다.
  • 시간이 바뀌면 목록에서 바로 시간 변경, 끝나면 완료 처리합니다.
  • 폼이 편하면 보강·일정 › 일정 등록을 사용합니다.

3. 학생 등록 · 리포트 · 운영 관리

신규 학생 등록·수정

  1. 학생 › 학생 등록·수정으로 이동합니다.
  2. 이름·학교·학년·연락처·학부모 연락처를 입력하고 반을 배정합니다. 등록 전 같은 이름 학생이 있는지 자동으로 확인됩니다.
  3. 정보 변경(반 이동, 연락처 변경, 휴원·퇴원)도 같은 화면에서 합니다.

학생 정보 찾기

학생 › 전체 학생에서 이름을 검색하면 학생 요약과 함께 학생 기록, 보강·상담·결석 등 전체 기록(Slack 학생기록 포함)을 한 화면에서 볼 수 있습니다. 학부모 문의에 답할 때 먼저 확인하세요.

학부모 리포트

  1. 리포트 › 학생 리포트에서 기간을 정하고 반·학교·학생 단위로 선택합니다.
  2. 출결·숙제·단어시험·진도 등 학습 현황이 정리된 리포트를 확인한 뒤 학부모님께 발송합니다.
참고 · 데일리브리핑이 바뀌었습니다

강사가 수업·코칭 기록 화면에서 만드는 데일리브리핑에 이제 【수업과목】이 들어가고, 1·2교시 또는 1·2·3교시로 나뉜 반은 마지막 교시에 하나로 통합된 브리핑이 만들어집니다.

반·조교·근무표

반·조교 관리에서 반 정보, 반별 조교 배정, 직원 근무표를 관리합니다. 근무표는 업무풀 자동배정에 쓰이므로(근무 중인 조교에게 배정) 바뀌면 바로 반영해 주세요. 퇴사·비활성 처리한 직원은 담당 반과 미완료 업무에서 자동으로 빠지고, 과거 기록에는 이름이 그대로 남습니다.

② '/' 빠른 명령 — 종류를 확실히 지정할 때

입력창에 / 를 치면 명령 목록이 열립니다. 명령을 붙이면 AI가 종류를 추측하지 않고 그 종류로만 저장하므로 가장 정확합니다.

TIP · /진도는 항상 '반 진도 기록'으로 저장

/진도로 시작하면 AI는 반·진도·과제·교시만 뽑아내고, 다른 종류로 판단되더라도 반 진도 기록으로 저장됩니다.

③ 되묻기와 확인

  • 학생 이름이 애매하거나(동명이인 등) 시간·날짜가 빠지면 AI가 질문을 합니다. 입력창에 답을 이어서 쓰면 됩니다.
  • 웹에서 보강·재시 같은 일정을 입력하면 '등록할까요?' 확인 창이 뜹니다. 내용을 보고 확인을 눌러야 저장됩니다.
  • 결과는 완료(저장됨) / 확인필요(정보 부족·애매함, 저장 안 됨) / 실패(오류)로 표시됩니다.

  • '취소·삭제·잘못·고쳐·바꿔' 같은 표현이 있으면 새로 저장하지 않고 기존 기록을 찾아 수정합니다.
  • 대상은 기본적으로 최근 24시간 안에 내가 입력한 기록입니다. 다른 사람이 입력한 기록은 고칠 수 없습니다(입력자에게 요청).
  • '최근 입력 보여줘'로 목록을 띄운 뒤 '2번 취소해줘'처럼 번호로 이어서 정정할 수도 있습니다.

5. Slack 사용법

Slack은 빠른 기록·알림·파일 업로드 창구입니다. 학생기록 채널에 쓴 메시지는 EXAM AI로 자동 전달되어 웹앱에 저장되고, 처리 결과는 메시지에 이모지 반응으로 표시됩니다.

TIP · 왜 '/' 대신 '!'를 쓰나요?

Slack은 '/'로 시작하는 글을 Slack 자체 명령으로 가로챕니다. 그래서 Slack에서는 웹의 '/' 빠른 명령을 '!'로 바꿔 씁니다. 명령 이름은 웹과 같습니다(!진도, !보강, !재시, !상담, !조치, !행정실, !결석, !긴급상담, !신입생상담, !레벨체크).

새 기능 · 학생기록 채널 밖에서도 기록됩니다

학생기록봇이 초대된 다른 팀 채널에서도, 우리 지점 재원생 이름이 들어간 메시지는 그 학생의 기록으로 저장됩니다. 학생과 관계없는 잡담에 학생 이름을 쓰지 않도록 주의해 주세요.

⚠ 주의할 점
  • Slack에서는 되묻는 화면이 없으므로 보강·재시 등 일정은 '등록할까요?' 확인 없이 바로 저장됩니다. 날짜·시간을 정확히 쓰세요.
  • 물음표 반응이 붙은 메시지에 스레드 답글을 달아도 처리되지 않습니다. 내용을 보충한 새 메시지로 다시 쓰세요.
  • 메시지를 수정·삭제하면 Slack 원문 기록은 따라 바뀌지만(삭제는 '삭제' 상태로 남음), 이미 저장된 보강·학생 기록은 바뀌지 않습니다. 이런 경우 웹 입력창에서 '정정'하세요.
  • Slack 표시 이름이 웹앱 직원 이름과 같아야 작성자가 정확히 기록됩니다. 프로필 이름을 실명으로 맞춰 주세요.
  • 학생기록은 지점별로 저장됩니다. 사직 Slack에 쓴 기록은 사직 학생에게만 연결됩니다.

③ 업무 알림 채널

업무가 누군가에게 배정되면 업무 알림 채널에 새 업무: 재시험 관리 · 김민수 → 홍조교 같은 메시지가 올라옵니다. 내 이름이 보이면 웹앱 업무 보드에서 확인·처리하세요.

④ 파일 올리기

보관 대상 채널에 파일을 첨부해 올리기만 하면 Google Drive에 자동 보관되고, 웹앱에서 검색할 수 있게 됩니다(다음 장).

전화 받으면서 휴대폰 Slack에 바로 남기고, 사무실에서는 웹 입력창을 쓰는 식으로 함께 쓰면 편합니다. 일정은 Slack에서 확인 없이 바로 저장되므로 날짜·시간을 정확히 쓰세요.

② 파일 찾는 방법

  1. 입력창에서 말로 찾기 — 거성중2 어순배열 파일 찾아줘, 최근 7일 파일, 24시간 이내 올라온 시험지
  2. 파일 화면에서 찾기 — 사이드바 파일·자료 › 파일 검색·최근 파일에서 최근 보관 목록과 검색을 사용합니다.
  3. 결과의 [Google Drive에서 열기]를 누르면 원본이 열립니다. Drive 접근 권한이 있는 Google 계정으로 로그인되어 있어야 합니다(권한이 없으면 원장님께 요청).
TIP · 잘 찾아지게 올리는 요령

파일명에 학교·학년·학기·시험·자료종류를 넣어 주세요. 예: 거성중2_2학기중간_어순배열.pdf. 검색은 파일명과 메시지 내용으로 찾기 때문에, 파일과 함께 짧은 설명을 쓰면 더 잘 찾아집니다. Mac에서 만든 한글 파일명도 정상 검색됩니다.

⚠ 알아둘 점
  • 학생 개인정보·상담 자료는 지점 안에서만 검색되지만, Drive 자체는 공용입니다. 민감한 파일은 꼭 필요한 채널에만 올려 주세요.
  • Slack에서 파일을 지워도 이미 Drive에 보관된 원본은 남습니다. 잘못 올린 파일 삭제가 필요하면 원장님께 알려 주세요.
  • 올린 직후 바로 검색되지 않으면 1~2분 뒤 다시 찾아보세요.
